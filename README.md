# HENA Odoo ERP

An ERP implementation project developed during my internship using Odoo Community, PostgreSQL, and Docker.

## Project Overview

The project simulates the ERP processes of a fictional e-commerce company named HENA in a containerized environment.

The main goal was to gain hands-on experience with ERP systems and understand how different business processes are connected within Odoo.

## Modules & Business Processes

The project includes practical work with:

- CRM
- Sales
- Purchase
- Inventory
- Invoicing
- Employees
- Project
- Helpdesk

Example workflows include:

- Customer and vendor management
- Product creation and inventory tracking
- Opportunity and quotation management
- Quotation → Sales Order → Delivery → Invoice workflow
- Purchase processes
- Employee and department configuration
- User access rights and permissions

## Technologies

- Odoo Community
- PostgreSQL
- Docker
- Docker Compose

## Environment

The project runs in a containerized environment with separate Odoo and PostgreSQL services managed using Docker Compose.

## Purpose

This repository documents the technical environment and practical ERP workflows explored during my internship.

> Note: The company and business data used in this project are fictional and were created for learning purposes.
